# Durable event journal implementation

`IS4-U03` stores each locked journal record and its embedded event as exact RFC 8785 bytes in PostgreSQL. The table has independent unique constraints for event ID, idempotency key, and `(run_id, sequence)`. A `SECURITY DEFINER` append function uses a fixed `pg_catalog, public` search path and a per-run transaction advisory lock before checking exact replay, conflicts, predecessor continuity, constant authority, lifecycle transitions, and terminal closure.

Update, delete, and truncate triggers reject mutation with `IS_JOURNAL_IMMUTABLE`. `PUBLIC` and `incidentseal_runner` receive no journal-table or append-function authority. The existing runner keeps only its bounded result-table privileges. There is deliberately no agent-facing append command: appending remains an internal host-control-plane operation for a later approved-workflow executor.

`incidentseal run events --run-id ID --jsonl` is read-only. It discovers an active database only when the container is bound to the exact topology contract and database image ID, queries exact retained `event_bytes` in sequence order, revalidates every canonical event, and writes those bytes unchanged as JSONL. The final event determines the existing distinct exit code: completed verdicts use `0/10/11/12`, cancelled uses `20`, failed `21`, stale `22`, and superseded `23`. An unknown run is `11`; absent or unreadable runtime custody is `74`.

`topology journal-probe --mode platform-validation --json` is a fixed synthetic real-surface validator. It can use and delete only the disposable project and volume named by `requirements/retained-runtime-volumes.lock.json`. It appends the frozen completed, stale, and superseded vectors, checks exact replay and database conflicts, invokes the real JSONL CLI, denies row mutation and runner reads, restarts PostgreSQL, verifies byte-identical persistence, compares all protected volume identities, and removes the disposable containers, network, and volume. It never reads approval or executes repository workflow input.
